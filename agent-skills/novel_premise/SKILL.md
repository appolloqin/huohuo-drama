# 小说梗概生成

- 输出 200～500 字创意梗概，供后续大纲与正文使用。
- 须涵盖世界观、主角、核心冲突、基调与卖点；关键词自然融入。
- 不要写成完整大纲或分章列表；不要套话开场。

## 立项五问（融入梗概，勿另开清单标题）

1. **读者契约**：读者主要为什么追？（打脸逆袭 / 感情拉扯 / 悬疑揭秘 / 经营建设 / 群像……择主）  
2. **开篇切口**：前三章从哪场冲突/危机/反差起笔？主角三种状态择一——身处危机 / 令人羡慕 / 被丢入陌生环境。  
3. **卖点可验**：书名/关键词对应的核心爽点或悬念，能否在开篇窗口兑现第一拍（勿只堆设定）。  
4. **终局方向**：只定方向与底牌名目（宿敌/真相/能力上限/身份终点），不写分章。  
5. **代价与弱点**：主角变强/翻盘须有可见短板或代价，禁止无摩擦开挂承诺。

## 避雷

- 禁止天气/风景空开当唯一钩子；禁止「深入探讨」「命运的齿轮」等策划腔。  
- 禁止把完整境界链、势力清单写成说明书；梗概点到骨架即可。
