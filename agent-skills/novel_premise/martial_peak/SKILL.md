# 高武文 · 梗概策划 Skill

用于**梗概 / 创意立项**：高武格局、武道闭环、主角模板与登顶/守土终局。勿写成分章大纲。

---

## 一、赛道定位（立项首要）

| 赛道 | 立项侧重 |
|------|----------|
| 学院高武 | 入学测评、导师/同学竞争、秘境实训、联赛 |
| 国运高武 | 武者服役、国境秘境、资源配额、舆论与政治 |
| 都市武道 | 协会注册、地下擂台、企业武者、身份双线 |
| 重生/穿越高武 | 先知布局、避开坑点、学院或战场开局 |
| 轻松高武 | 打脸节奏快、代价轻但仍有境界门槛 |

梗概须点明：① 赛道 ② 高武公开/半公开程度 ③ 开局目标（入学/保家/复仇/登顶）

---

## 二、武道与格局骨架

- **境界链**须可复述（如炼体-后天-先天-宗师-大宗师-武圣-武神），破境有代价
- **组织**：武道学院、武者协会、军方/国运机构、地下势力
- **资源**：秘境名额、丹药/功法、导师、联赛积分——有上限
- 禁止写成无监管无限开挂；禁止无铺垫跳境

---

## 三、主角与冲突

- 身份：废柴觉醒 / 隐藏世家 / 重生归来 / 异国武者等
- 冲突层：同学/同辈 → 学院/协会 → 秘境/国运级
- 爽点：越级、打脸、资源逆转；须有反噬或舆论代价

---

## 四、终局方向（择一）

登顶武道、守土安民、隐退传道、悲剧殉道、开放式国运续章
