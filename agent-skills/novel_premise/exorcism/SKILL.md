# 驱魔文 · 梗概策划 Skill

用于**梗概 / 创意立项**：道门秩序、邪祟体系、符箓阵法与斗法成长方向。勿写成分章大纲。

**与诡异区分**：有明确斗法与道行成长，非纯规则怪谈避战。  
**与仙侠区分**：贴近民俗道门/都市灵异，弱化三界修仙与渡劫飞升。

---

## 一、世界观（立项核心）

### 场域

现代都市、县城、旧楼、医院、义庄、道观、夜路、废弃工厂——**邪祟借人气与阴地滋生**。

梗概须点明：① 道门/民间术法如何存在（公开/隐秘/异端）② 邪祟来源（怨灵、古尸、地煞、境外邪物）③ 主角为何卷入（传承、事故、被迫觉醒）。

### 道行体系骨架

| 层级 | 立项要素 |
|------|----------|
| 入门 | 识煞、画符、开眼、基础法器 |
| 小成 | 符箓成套、阵法雏形、炼体防反噬 |
| 中坚 | 收服、借法、法器温养、道行压制 |
| 高阶 | 开坛、镇域、禁术代价、道门博弈 |

**约束**：每次施法有消耗（炁/精血/法器耐久/心魔）；越级须有代价或外援。

---

## 二、主角与冲突

### 主角模板

- 异端传承 / 野路子道士 / 现代灵魂穿入道门弃徒 / 天生阴阳眼
- 道心取向：守序除魔 /  pragmatic 以术换命 / 复仇驱邪

### 核心冲突

| 类型 | 示例 |
|------|------|
| 邪祟 | 怨灵索命、古尸破封、群煞围楼 |
| 道门 | 正统排斥、禁术诱惑、传承争夺 |
| 世俗 | 隐瞒身份、警方介入、亲友被牵连 |
| 自身 | 反噬、心魔、禁术侵蚀 |

梗概须含**至少一场可想象的斗法/开坛节点**（非「后来成为大师」一句带过）。

---

## 三、立项避雷

- 禁止纯 KPI 梗概：「收服×3、突破×2、打脸×5」
- 禁止只有设定说明书，无人物欲望与具体首案
- 开章方向优先**异象/现场/物件**（符燃、尸动、夜哭），非家世年表
