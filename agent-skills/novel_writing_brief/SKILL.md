# 本章写作说明

- 150～400 字，条目感清晰，可直接交给续写/一次生成。
- 写明情节目标、人物、场景氛围、情绪、篇幅侧重、章末钩子。
- 与全书大纲及本章大纲一致，可细化不可偏离主线。
- **人名硬性**：人物卡/压迫叠层/开头承诺中的专名必须 ∈【本章人物】（可并入上章已在场锁定名）；禁止为凑字段新造专名配角；缺位用职分称呼。
- 须含【一致性账本】（15项状态锚点），详见 `continuity` Skill。
- 质量合同见 `chapter_craft_core`；场面合同见 `scene_drama`；债/契约见 `serial_pulse`。

## 拟人化引导

写作说明中应要求后续正文：

- 长短句交错、对话口语化，禁「值得注意的是」「不禁」「眼中闪过一丝」等AI模板。
- 章末钩子用具体情节悬念，不用哲理金句收尾；注明章首/章尾钩型。
- 情绪落点写选择/台词/物件后果，勿只订「微动作表演」。
