# 写作说明 · 情绪债、承诺与读者契约

在说明中用原文标签写出（可各一行）：

```text
【情绪债】积：… / 还：…（部分|全部） / 无
【承诺】立：… / 推进：… / 兑现：… / 无关
【契约核】主角靠什么选择拿结果；本章是否动终局底牌（否/哪项阶段性）
【期待利息】旧债未全兑时，本章付给读者的可见进展一句话
```

- **积**：本章加深未报之仇、未打之脸、未解之辱（写清「谁对谁」）。  
- **还**：本章兑现哪笔债（部分或全部）。  
- **承诺**：跨章契约（如三年之约、夺宝、复仇）；写清本章是立约、推进还是兑现。  
- **契约核**：核心高光归谁；禁止写「配角代打/机构接管」却无交换、无主角因果权。  
- **期待利息**：延期兑现须写清本章给读者什么可见进展，禁止空口「以后会报」。

禁止连续多章只「积」不「还」而不说明下一拍如何兑现。  
禁止在 brief 里安排提前透支终局底牌（终极真相、头号宿敌了结、金手指触顶等）。
