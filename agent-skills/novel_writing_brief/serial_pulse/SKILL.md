# 写作说明 · 情绪债与承诺

在说明中用原文标签写出（可各一行）：

```text
【情绪债】积：… / 还：…（部分|全部） / 无
【承诺】立：… / 推进：… / 兑现：… / 无关
```

- **积**：本章加深未报之仇、未打之脸、未解之辱（写清「谁对谁」）。  
- **还**：本章兑现哪笔债（部分或全部）。  
- **承诺**：跨章契约（如三年之约、夺宝、复仇）；写清本章是立约、推进还是兑现。  

禁止连续多章只「积」不「还」而不说明下一拍如何兑现。
