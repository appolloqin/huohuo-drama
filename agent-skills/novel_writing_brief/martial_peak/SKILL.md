# 高武文 · 本章写作说明 Skill

生成本章 **150～400 字写作说明**，供续写 / 一次生成使用。须对齐大纲与本章概要。

---

## 写作说明必含条目

1. **本章情节目标**：四段式哪一阶段；训练/任务/秘境哪一环
2. **境界状态**：当前境；是否破境或反噬；功法/兵器
3. **出场人物**与阵营；竞争或同盟变化
4. **冲突类型**：测评/联赛/秘境/协会规则/国运（至少一类）
5. **场景**：学院、都市擂台、秘境、边境等
6. **章末钩子**：排名、名额、曝光、越级对手或任务升级

---

## 打斗与代价

写明内力/气血消耗、功法弊端或舆论后果；禁流水账无脑碾压

---

## 氛围

现代器械与武道并存时可写监控、直播、协会规章；忌纯古风武侠串味除非本书设定如此
