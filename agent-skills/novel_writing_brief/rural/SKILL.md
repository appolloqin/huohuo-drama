# 乡村文 · 本章写作说明 Skill

生成本章 **150～400 字写作说明**，供续写 / 一次生成使用。须对齐大纲与本章概要。

---

## 写作说明必含条目

1. **本章情节目标**：立局/循环/升级/终局哪一段
2. **经营或事务进度**：种养、工程、生意、调解等推进什么
3. **出场人物**与人情关系变化（面子、闲话、站队）
4. **冲突类型**：闲话、抢资源、欺压、观念、销路（至少一类）
5. **场景**：村口、田地、集市、堂屋、村委会等
6. **章末钩子**：新闲话、新订单、新威胁或阶段性收获

---

## 氛围

炊烟、泥土、方言口语适度、季节感；忌都市偶像剧腔与修真术语
