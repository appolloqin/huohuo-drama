# 本章写作说明 · 章节质量核心

**优先于**题材风格 Skill：先保证戏，再套类型套路。  
**场面合同**见横切 Skill `scene_drama`（与下列字段对齐）。

## Meta 写法契约（写入说明口吻；禁止冒充 pacing 检测条款）

- 短平快；开篇冲突或对白；章尾挖坑；书名/梗概卖点尽早可见。  
- **禁止**写「须在前三分之一短平快/对白开篇」这类元指令当节奏条款。  
- 若需要节奏落地条款，必须写成可核对事件：`须在前三分之一篇幅内写到【具体冲突事件】`。

## 必须写清（条目可短，字段不可缺）

1. **章功能**：推进情节 / 加深人物 / 抬高张力 / 改变局势 —— 至少勾选 **2** 项并各一句说明。  
2. **开头承诺**：前 300～800 字读者看什么、谁在赌什么（禁止「先堆设定」）。  
3. **场景目标**：主角本章要得到 / 阻止 / 查明 / 隐藏什么（一句话）。  
4. **冲突与代价**：谁会肉疼；赢也要有代价。  
5. **信息增量**：本章新事实 / 新关系 / 新危险 / 推翻旧认知。  
6. **关键选择**：哪个转折由人物选择触发（动机可复述）。  
7. **章末问题**：具体问题（新变数/坏消息/错误决定/暴露/倒计时），禁止「睡了/天亮了/欲知后事」。  
8. **主线贡献**：若删掉本章，主线是否仍通顺？不通顺才算合格功能章。  
9. **人物卡**（D2）：出场有台词者 — 欲望 / 怕 / 说话习惯（可各半句）。  
10. **压迫叠层**（D4）：≥3 项。  
11. **本场独有动作**（D5）：1 项。  
12. **爽点失态+压场**（D6）：若本章含翻盘 — 失态类型 + 压场 seed。

## 文风取向

浅白追更优先；面子与胜负一眼能懂；勿用哲理金句当钩子；brief 须可执行，勿只写梗概。
