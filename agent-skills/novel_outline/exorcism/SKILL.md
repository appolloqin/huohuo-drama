# 驱魔文 · 大纲 Skill

用于**全书大纲**：首案入局 → 道行小成 → 邪祟升级 → 道门/禁术终局。须规划**可见斗法场面**，非状态清单。

---

## 大纲通用结构

1. **总纲**：道门格局、邪祟威胁、主角传承与终局方向
2. **主要人物**：道士/邪祟/凡人各 2～4 人，标注术法特长与短板
3. **分章概要**：标注本章若有**开坛/修炼/斗法**，须写清场面目标与代价

---

## 分章规划要点

### 开局（前 10%～15%）

- **物件/异象/现场**入场：符纸自燃、尸变、夜哭、煞气肉眼可见
- 第一章宜有**小规模交锋或开坛**（试探→代价→余波），禁止纯背景介绍

### 主体

- 道行与法器**通过案件/斗法递进**，非「闭关三月突破」一笔
- 大纲中斗法章须含：**试探 → 交锋 → 消耗 → 余波** 四步
- 收服/破煞/镇域各类型错开，避免每章同一模板

### 章末钩子

- 未收服的邪祟余孽 / 道门追杀令 / 禁术诱惑 / 亲友被盯上

---

## 场面硬约束（写入分章标签时遵守）

1. **修炼/开坛**：须规划身体感（炁行、符热、耳鸣、虚脱），禁止仅写「道行+1」
2. **斗法**：至少一轮往来；写清符箓/法器消耗与失败风险
3. **禁止**：整章 KPI 清单（收服×1、突破×1）
