# 高武文 · 大纲 Skill

用于**全书大纲**：入局测评 → 成长循环 → 格局升级 → 武道终局。须与梗概境界与组织一致。

---

## 大纲通用结构

1. **总纲**（150～300 字）：高武格局、核心恩怨、武道体系、国运/学院线、结局类型
2. **主要人物**：主角 + 导师/对手/队友；每人标注**境界、阵营、动机**
3. **分章概要**：每章含章末钩子；标注境界进度、资源线、冲突节点

---

## 四段式分章规划

### 第一段：入局（前 10%～15%）

测评落榜/意外觉醒/秘境余波/任务失败——立刻立目标与第一个对手

### 第二段：循环成长（中段主量）

训练—任务/秘境—打脸或受挫—资源结算—下一次门槛；穿插人情与阵营试探

### 第三段：格局升级（后段）

国运级任务、跨校/跨国对手、功法反噬或身份曝光

### 第四段：终局

登顶对决、守土大战、或代价式圆满；回收境界与人物线
