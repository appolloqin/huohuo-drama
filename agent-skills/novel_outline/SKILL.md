# 小说大纲生成

- 结构：世界观设定 → 总纲（含戏剧总纲标签）→ 主要人物 → 分卷设计 → 分章概要。
- 总纲后必须写：`【主题】` `【世界规则】` `【主角欲望·外】` `【主角欲望·内】` `【主角弱点】` `【人物核心】` `【结局方向】` `【情绪调性】`。
- 每章：`第N章：标题`，其下带齐  
  `【本章时间】【本章地点】【本章人物】【本章起因】【欲望】【阻碍】【局面变化】【人物选择】【冲突层】【情绪手法】【章末问题】【信息增量】【主题回响】`。  
  `【冲突层】`：外部 / 人际 / 自我（可多选）。
- 人物姓名、动机、关系须具体；与梗概设定一致。
- 分章须预埋状态递进与伏笔回收，禁止境界/关系无故倒退；详见 `continuity` Skill。
