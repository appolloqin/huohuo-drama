# 小说大纲生成

- 结构：世界观设定 → 总纲（含戏剧总纲标签）→ 主要人物 → 分卷设计 → 分章概要。
- 总纲后必须写：`【主题】` `【世界规则】` `【主角欲望·外】` `【主角欲望·内】` `【主角弱点】` `【人物核心】` `【结局方向】` `【情绪调性】`；并写 `【卖点偏转】` `【非常规压力源】` `【能力非常规用法】`。
- 总纲另须写：`【读者契约】`（读者主要为看主角解决问题 / 群像 / 导师托举 / 制度建设，择一）；`【终局底牌】`（头号宿敌、终极真相/身世、金手指上限、身份终点——各标最早可解锁卷）；`【升级台阶】`（境界/地图/势力档数须撑住目标篇幅，禁止前半程打光）。可选：`【贯穿道具】` 1～2 件（三次出现：建义→颠覆→暴击，各标卷/章位）。
- 每章：`第N章：场面短标题`（标题行禁止括号/破折号夹注），其下分字段带齐  
  `【本章时间】【本章地点】【本章人物】【本章起因】【欲望】【阻碍】【局面变化】【人物选择】【冲突层】【情绪手法】【章末问题】【信息增量】【主题回响】`；第1～8章另须带齐 `【恨】【爽】【急】【盼】【爽型】`；爽型闭集只写在【爽型】行：`硬撕|拒签|揭穿假账|示弱钓鱼|当众对赌|借力第三方`。  
  `【冲突层】`：外部 / 人际 / 自我（可多选）。正例：`第1章：签到百兵` 下一行 `【本章时间】穿越当日卯时`，勿写成标题后括号夹注。
- **章级吸引力**：第1～8章须写**显式**四拍（第三版三刀）——`【恨】`冲突前置；`【爽】`**动作震慑**+**本事露尖**（立约可留但不得单独当爽；本事本拍首亮）；`【急】`尖期限+拢共天数；`【盼】`**一句**缺一环/短复验（禁翻找过程段）。并与起因/阻碍、选择/局面、章末问题、信息增量一致。正文人物人数须对齐【本章人物】。章尾禁温情泄压与「没准谱」。另：`【本章起因】`与`【恨】`须冲突切口且第1～5章写明**谁施压、要什么**；禁止「冻醒/哭喊认亲」唯一起因；`【信息增量】`/`【盼】`卖点须能开篇兑现；`【局面变化】`须局势推进；`【章末问题】`/`【急】`须未决具体事件。
- **人物定名**：【主要人物】每人 `姓名｜称谓/身份｜关系｜动机`；绰号用竖线不用括号。父/母/叔伯等凡有戏份必须定名；同辈字辈一致。`【本章人物】`列姓名，不得只写「父亲/叔叔」。
- 人物姓名、动机、关系须具体；与梗概设定一致。
- 分章须预埋状态递进与伏笔回收，禁止境界/关系无故倒退；详见 `continuity` Skill。章尾钩型与债钩详见 `chapter_hooks` Skill。
