# 全书大纲 · 分章钩子

【分章概要】每章须含戏剧标签（时间/地点/人物/起因/欲望/阻碍/局面变化/人物选择/冲突层/情绪手法/章末问题/信息增量/主题回响）。

可选增强：

`第N章：标题` 后可加 `【章职】hook_setup|pressure|payoff|breath|travel` 与债/契约钩。

同一卷内避免连续多章同为 `payoff` 同强度；须有 `pressure`/`breath` 交替。  
开篇数十章内宜尽早出现可跨章兑现的**承诺或大辱**，便于后续还债。
