# 全书大纲 · 分章钩子

【分章概要】每章须含戏剧标签（时间/地点/人物/起因/欲望/阻碍/局面变化/人物选择/冲突层/情绪手法/章末问题/信息增量/主题回响）。

**硬性：**
- 【章末问题】= 未决具体下一拍事件（谁/什么尚未落地），禁止空泛感叹。
- 【本章起因】= 冲突切口；第1～5章须写明谁（姓名）施压、要什么，该人须出场；禁止「冻醒/哭喊认亲」唯一起因。
- 第1～5章【信息增量】须出现可跨章兑现的**承诺、大辱或身份卖点冲突**，且能在开篇窗口兑现。
- 【本章人物】= 本章出场或被具体提及者的**姓名**（可附称谓）；【阻碍】等叙述禁止无名称谓（父亲/叔伯/队长）占位，须与【主要人物】定名一致；同辈父/叔伯须字辈一致。

可选增强：

`第N章：标题` 后可加 `【章职】hook_setup|pressure|payoff|breath|travel` 与债/契约钩。

同一卷内避免连续多章同为 `payoff` 同强度；须有 `pressure`/`breath` 交替。  
开篇数十章内宜尽早出现可跨章兑现的**承诺或大辱**，便于后续还债。
