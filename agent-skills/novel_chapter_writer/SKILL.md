# 小说章节正文

- 长篇网文叙事，非短剧剧本；纯正文，无章节标题行与作者按语。
- 续写时只输出新增段落；一次生成时写完整章。
- 须衔接上一章结尾与全书大纲；人称、时态、人物性格前后一致。
- **15项一致性**：环境、境界、资源、人设、伤势、时间等须对齐前文，禁止无铺垫突变与吃书；详见 `continuity` Skill。
- **戏剧与契约**：场面先过 `scene_drama`；质量/钩子/情绪落地见 `chapter_craft_core`；债与契约四问见 `serial_pulse`。
- 全文简体中文，禁止中英夹杂。

## 人写网文（生成时遵守）

1. **段落**：长短自然变化（对话/转折可 1 句成段，叙述常见 2～3 句）；段间空一行；忌诗化碎行，忌每段固定句数。叙述默认用逗号串起 2～4 件事再落句号；禁通篇电报碎句。
2. **语气**：对话与叙述适度用语气词（吧、呢、啊、嗯、啧 等）；对话用中文双引号 “……” 表迟疑，勿用直角引号「」。
3. **画面感**：五感具体；拟声如 “轰隆——” 可独立一行，少量即可。
4. **禁 AI 套话**：值得注意的是、不禁、至关重要、眼中闪过一丝、嘴角勾起一抹、「不是A而是B」公式等。
5. **禁止无铺垫发明**：前序/大纲未写的怀孕等重大状态不得突然出现（含「肚子里那块肉」类脑补）；只写家人挨饿即可。
6. **章尾**：落到未决具体事件/物件；禁哲理升华与「他不知道的是，更大的风暴…」预告腔。
