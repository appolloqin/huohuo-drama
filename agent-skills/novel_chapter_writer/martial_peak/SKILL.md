# 高武文 · 章节正文 Skill

撰写 / 续写**高武文章节正文**。境界可量化但有代价，爽点与压迫交替。

---

## 正文通用原则

1. **境界自洽**：名称与层级全书一致；破境须铺垫
2. **规则感**：学院规章、协会注册、秘境名额、国运任务可感知
3. **代价**：透支、反噬、伤病、舆论、处分——至少一种落地
4. **网文排版**：段落自然变化，段间空一行；对话有口气；忌 AI 套话
5. **简体中文**

---

## 场景与节奏

- 测评/训练：数据、教官、同学目光
- 对战：招式意图 + 身体反馈 + 胜负转折
- 秘境：资源争夺与环境威胁并行
- 日常：食堂、宿舍、直播热搜可作缓冲，勿注水
