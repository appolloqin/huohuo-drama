# 正文 · 情绪债、承诺与读者契约

写作说明中的 `【情绪债】` `【承诺】` 对本章有约束力：

- 标了「还」：正文须让读者感到这笔债被部分或全部清偿（场面可短，意图须明）。  
- 标了「推进」契约：须出现可感知的进度（倒计时、备战、阻碍），禁止空口旁白。  
- 标了「积」：须有具体羞辱/压迫场面，禁止抽象说「他很屈辱」。

## 契约四问（写前/写后各过一遍）

1. **因果+结算**：本章关键结果是否由主角（或其承诺所有者）的选择挣来？禁止巧合/配角无声夺走高光。  
2. **利益安全**：核心收益、打脸、身份兑现有没有被机构/旁观者替主角消化？旁观可放大，不可替代。  
3. **终局储备**：有没有提前动用终局底牌（终极真相/头号宿敌了结/金手指触顶/身份终点）或把升级线打到天花板？有则改轻为阶段性进展。  
4. **期待债利息**：旧承诺若未全兑，本章须付利息（新信息、局势变化、阶段小胜或更清晰下一目标）；禁止用换地图/换机构逃避旧债。

**爽文例外**：当面碾压本身就是契约时，不得用「布局代理」让主角划水。群像/导师/经营文须开篇已承诺期待归属。
