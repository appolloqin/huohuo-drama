# 章节正文 · 质量核心

**优先于**题材风格与「为反 AI 而反 AI」：先保证戏剧功能。  
**场面怎么演**见横切 Skill `scene_drama`（D1～D6）。  
**债与契约**见 `serial_pulse`。  
写后多维审稿见独立 Agent `novel_review`（找问题，不改正文）。

## 章内至少完成四件事中的两项

| 功能 | 可执行（对齐 scene_drama） |
|------|---------------------------|
| 推进情节 | 通过 **D1 演**出来，非作者综述 |
| 加深人物 | **D2** 人物可记住；对峙段 **D3** 具体闪念 |
| 抬高张力 | **D4** 压迫叠层 ≥3 |
| 改变局势 | 翻转场 **D6** 失态+压场 |

## 硬看点

- **争执/压迫场先过 D1～D5 自检，再考虑短平快。**
- **短平快**：开篇优先对白或冲突动作；环境**一句锚**，禁整段 GPS/设定播报。  
- 第2章起：先承接上章事实/落地起因，再爆发冲突（禁止为酷开篇吃书）。  
- 有明确场景目标与代价；有信息增量。  
- 关键转折由人物选择驱动。  
- 章末留下**未决具体事件**，禁止纯感慨收束。  
- 删掉本章应伤主线；否则应收束为短过渡（见章职 Skill）。  
- **禁止灌水凑字**：无冲突、无新信息、无关系变化的段落删掉。

## 情绪落地（禁默认微动作）

写到情绪节点时按序取**一种**最有信息量的落点，勿叠「动作+身体+比喻+心理解说」四重注释：

1. 上下文已够 → 删补充，直接下一句  
2. 情绪改变下一步 → 写选择 / 台词 / 策略 / 代价  
3. 场内物件能承载 → 写合同、药、门、消息等**当场已有物**的变化  
4. 身体确有后果 → 动作失败、疼痛、失衡；无后果的「指尖/指节/目光/呼吸一下」优先删  
5. 直写更准 → 「他听烦了」可保留，不必绕成表演

**套式反应删除测试**：删掉后信息/选择/关系/物理结果无损失 → 删；换人名换房间仍成立 → 改成角色专属细节。

## 章首 / 章尾钩子（按本章情绪选型）

**章首**（择一，勿天气/风景空开）：悬念对话｜倒计时｜未完成动作｜反差场景｜意象预示。  
**章尾**（择一，须落到具体事件/物件，禁哲理升华与「他不知道的是…」预告腔）：

| 情绪阶段 | 推荐钩子 |
|----------|----------|
| 悬念/未知 | 突然揭示 / 神秘物品 / 留白（只写反应不揭因） |
| 紧迫/危机 | 紧急危机 / 倒计时 / 未完成动作被打断 |
| 反转/真相 | 身份反转 / 隐藏含义 / 回声（尾句呼应开头但关键细节变了） |
| 情感/关系 | 两难抉择 / 承诺或威胁 / 情感转折 |
| 氛围/日常 | 意象变化 / 离奇消失 / 信息差 |

第1章钩子须强；中期日常可用中强度；禁止章尾温情泄压把急/盼泄掉。

## 自检（写完心里过一遍）

目标一句话？局势相对开头是否不可逆变了？最精彩处是人物选择还是作者解释？连续两页是否无冲突/无新信息？D1～D6 是否过？章尾是否留下未决具体事件？情绪段是否靠选择/物件而非微动作刷屏？

## 文风

浅白清楚，但**戏须演出来**；对白推进关系或信息，不轮流演讲；禁作者播报整段世界观。
