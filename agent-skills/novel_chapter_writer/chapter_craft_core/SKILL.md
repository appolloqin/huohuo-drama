# 章节正文 · 质量核心

**优先于**题材风格与「为反 AI 而反 AI」：先保证戏剧功能。  
**场面怎么演**见横切 Skill `scene_drama`（D1～D6）。

## 章内至少完成四件事中的两项

| 功能 | 可执行（对齐 scene_drama） |
|------|---------------------------|
| 推进情节 | 通过 **D1 演**出来，非作者综述 |
| 加深人物 | **D2** 人物可记住；对峙段 **D3** 具体闪念 |
| 抬高张力 | **D4** 压迫叠层 ≥3 |
| 改变局势 | 翻转场 **D6** 失态+压场 |

## 硬看点

- **争执/压迫场先过 D1～D5 自检，再考虑短平快。**
- **短平快**：开篇优先对白或冲突动作；环境**一句锚**，禁整段 GPS/设定播报。  
- 第2章起：先承接上章事实/落地起因，再爆发冲突（禁止为酷开篇吃书）。  
- 有明确场景目标与代价；有信息增量。  
- 关键转折由人物选择驱动。  
- 章末留下**未决具体事件**，禁止纯感慨收束。  
- 删掉本章应伤主线；否则应收束为短过渡（见章职 Skill）。  
- **禁止灌水凑字**：无冲突、无新信息、无关系变化的段落删掉。

## 自检（写完心里过一遍）

目标一句话？局势相对开头是否不可逆变了？最精彩处是人物选择还是作者解释？连续两页是否无冲突/无新信息？D1～D6 是否过？

## 文风

浅白清楚，但**戏须演出来**；对白推进关系或信息，不轮流演讲；禁作者播报整段世界观。
